Building your first set

A complete American Mahjong setup needs three things: a 160-tile set, four racks with pushers and something to store it all in. If you are starting from scratch, pick your tile set first, because it sets the look of the whole table. Then match racks in a coordinating color, and add a storage bag so the set travels well to game nights.

Which size racks should you pick?

17.5 or 18.5-inch racks suit most standard tiles and smaller tables.

20-inch racks give more room for larger tiles and look more premium.

Magnetic detached pushers are easier to handle and store than attached ones.

Check the tile size on your set before choosing, so your tiles sit neatly on the rack.
